The Dotlet API uses two different pagination styles, depending on the endpoint.

## Page-based pagination

[`GET /registrar/orders`](/api-reference/orders/list-orders) uses page numbers.

| Parameter | Default | Description |
|---|---|---|
| `page` | `1` | The page to return. |
| `page_size` | `10` | Items per page. |
| `order_status` | — | Optional filter by order status. |

The response includes everything you need to build pagination controls:

```json
{
  "items": [ /* ... */ ],
  "total": 47,
  "page": 1,
  "page_size": 10,
  "total_pages": 5
}
```

Request the next page by incrementing `page`:

<CodeGroup>

```bash cURL
curl "https://api.dotlet.net/api/v1/registrar/orders?page=2&page_size=10" \
  -H "X-API-Key: dk_••••••••••••••••"
```

```javascript JavaScript
const response = await fetch('https://api.dotlet.net/api/v1/registrar/orders?page=2&page_size=10', {
  headers: { 'X-API-Key': 'dk_••••••••••••••••' }
});
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    'https://api.dotlet.net/api/v1/registrar/orders',
    headers={'X-API-Key': 'dk_••••••••••••••••'},
    params={'page': 2, 'page_size': 10}
)
print(response.json())
```

```go Go
package main

import (
	"fmt"
	"io"
	"net/http"
)

func main() {
	req, _ := http.NewRequest("GET", "https://api.dotlet.net/api/v1/registrar/orders?page=2&page_size=10", nil)
	req.Header.Set("X-API-Key", "dk_••••••••••••••••")

	resp, _ := http.DefaultClient.Do(req)
	defer resp.Body.Close()

	body, _ := io.ReadAll(resp.Body)
	fmt.Println(string(body))
}
```

</CodeGroup>

Stop once `page` equals `total_pages`.

## Offset-based pagination

[`GET /dns/{domain_name}/records`](/api-reference/dns/list-dns-records) uses `skip` and `limit` instead.

| Parameter | Default | Description |
|---|---|---|
| `skip` | `0` | Number of records to skip. |
| `limit` | `100` | Maximum records to return. |

<CodeGroup>

```bash cURL
curl "https://api.dotlet.net/api/v1/registrar/dns/acmewidgets.com/records?skip=100&limit=100" \
  -H "X-API-Key: dk_••••••••••••••••"
```

```javascript JavaScript
const response = await fetch('https://api.dotlet.net/api/v1/registrar/dns/acmewidgets.com/records?skip=100&limit=100', {
  headers: { 'X-API-Key': 'dk_••••••••••••••••' }
});
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(

    params={'skip': 100, 'limit': 100}
```

```go Go
package main

import (
	"fmt"
	"io"
```

</CodeGroup>

This endpoint returns a plain array rather than a wrapped object — when the array's length is smaller than `limit`, you've reached the end of the list.
