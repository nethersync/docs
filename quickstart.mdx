title: "Quickstart"
description: "Check a domain's availability and register it, in under 10 minutes."
---

This guide takes you from an API key to a registered domain. By the end, you'll have checked a domain's availability, seen its price, and purchased it through the API.

**Time:** ~10 minutes

## Prerequisites

- A Dotlet account with an API key. See [Authentication](/authentication) if you don't have one yet.
- `curl`, or any HTTP client.

## Step 1: Check domain availability

Send a `GET` request with the domain you want, in the path.

```bash
curl https://api.dotlet.com/api/v1/registrar/availability/example.com \
  -H "X-API-Key: dlt_live_••••••••••••••••"
```

A domain that's free to register returns `available: true`:

```json
{
  "domain": "example.com",
  "available": true,
  "status": "available",
  "premium": false,
  "price": "12.99",
  "currency": "USD"
}
```

If `available` is `false`, pick a different domain or try one of its suggested alternatives — see [Search and register a domain](/guides/search-and-register-a-domain) for keyword-based search.

## Step 2: Purchase the domain

Once you've found an available domain, register it with a single `POST` request. Registration requires a registrant contact — this is the person or organization the domain will be registered to.

```bash
curl -X POST https://api.dotlet.com/api/v1/registrar/purchase \
  -H "X-API-Key: dlt_live_••••••••••••••••" \
  -H "Content-Type: application/json" \
  -d '{
    "domain": "example.com",
    "years": 1,
    "contact": {
      "first_name": "Ada",
      "last_name": "Lovelace",
      "email": "ada@example.com",
      "phone": "+14155550100",
      "address1": "123 Main St",
      "city": "San Francisco",
      "state": "CA",
      "postal_code": "94105",
      "country": "US"
    },
    "privacy": true,
    "auto_renew": true
  }'
```

A successful purchase returns the new domain's order ID and registration details:

```json
{
  "success": true,
  "domain": "example.com",
  "order_id": "8f14e45f-ceea-467e-bd6a-15e6e4f8c2f1",
  "registration_date": "2026-06-30T00:00:00Z",
  "expiry_date": "2027-06-30T00:00:00Z",
  "nameservers": []
}
```

<Note>
  `/registrar/purchase` is a billable action that charges your account immediately. To review pricing and contact details before charging, create an order with [`POST /registrar/order`](/api-reference/orders/create-order) first, then complete it from your dashboard.
</Note>

## Step 3: Confirm the domain is yours

List your registered domains to confirm the purchase went through.

```bash
curl https://api.dotlet.com/api/v1/registrar/domains \
  -H "X-API-Key: dlt_live_••••••••••••••••"
```

`example.com` should now appear in the response with a `registration_status` of `active`.
